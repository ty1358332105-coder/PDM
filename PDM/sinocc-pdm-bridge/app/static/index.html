📊 流程查询（输入物料编码）
说明：输入根物料编码 → 自动生成整棵 BOM 多层明细；每行物料自动标记当前 流程未结束 的样品确认单（101）和变更流程单（91046），蓝色高亮；流程已结束/归档的不会显示。
⚠ 层级越多查询越慢：首次需逐个物料扫描关联对象流程状态（全树几百行约 1~4 分钟，二次起有缓存秒开），建议先用少层级。
📤 导出平面件（输入物料编码）
说明：输入根物料编码后显示完整多层明细，重点置顶 接线铭牌、铭牌、机型标、说明书、能效标、故障代码 并列出技术文档；其他物料也显示，行右键可打开操作菜单。技术文档可单独打开。
🔀 BOM 比对（输入两个物料编码）
说明：分别取两个根物料的多层明细，按物料编码逐项比对并高亮 仅 A 有 / 仅 B 有 / 数量不同；可勾选「只看差异点」快速定位变化。
🧾 确认单查询（输入整机 / 物料编码）
说明：输入根物料编码 → 展开整棵 BOM 多层明细；逐行物料列出其全部样品确认单 （不区分流程状态，已审批归档的也列出）：TC = 临时确认、 SC = 正式确认，分两列展示，同一物料多张确认单放在同一行； 每张确认单显示「编码 + 供应商全称 + 简称」，点击编码可查看确认单详情。可导出 Excel。
时间窗与「流程查询」同口径：只查物料受控时间在窗内的物料，且只列确认单编制时间在窗内的确认单；要看某物料历史全量请选「不限」。
⚠ 每张确认单都要单独取一次明细（拿供应商），层级越深越慢；首次全树几百行约 1~3 分钟，二次起有缓存秒开。
